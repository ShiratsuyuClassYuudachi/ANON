# ANON 功能介绍

ANON 是一个面向活动（展会、同人活动、演出等）组织团队的全流程追踪与管理工具。系统以「项目」为单位组织协作，覆盖任务进度、财务收支、物料文件与平台账号四大场景，支持移动端优先的 Web 访问。

- 技术栈：Express + TypeScript + MongoDB（后端），Vite + React + TypeScript（前端）
- 接口契约见 `docs/api.md`，部署与运维见 `docs/readme.md`

---

## 账号与权限

### 注册与登录

- **邀请码注册**：普通用户必须凭邀请码注册，邀请码由超级管理员在「管理」页创建（可自动生成或自定义），每个邀请码仅可使用一次，注册时记录所用邀请码
- **首个超级管理员**：系统初始状态下，使用环境变量 `SUPER_ADMIN_EMAIL` 指定邮箱注册的第一个账号自动成为超级管理员，无需邀请码
- 密码使用 bcrypt（cost 12）哈希存储，登录态为 JWT（30 天有效）

### 个人资料

- 用户可维护昵称与**联系方式列表**（平台 + 账号，如 QQ、微信），联系方式会展示给项目成员，方便协作对接

### 项目权限模型

- 创建项目的用户自动成为项目成员并获得「主办」角色（全部权限）
- **预置角色**：主办（管理）、美工、宣发、一般 staff，各带符合工作内容的默认权限；可在项目内修改
- **自定义角色**：可自由创建角色并勾选权限点
- 权限点一览：

| 权限点 | 说明 |
| --- | --- |
| `project:manage` | 项目管理（等价于拥有全部权限） |
| `member:manage` | 成员管理（邀请、改角色、移除） |
| `role:manage` | 角色管理 |
| `todo:manage` | 待办管理（增删改任意待办） |
| `todo:complete` | 完成指派给自己的待办 |
| `file:upload` | 上传文件 |
| `finance:manage` | 财务管理 |
| `materials:manage` | 物料管理 |
| `accounts:manage` | 账号管理 |

- **成员邀请**：项目管理员可生成邀请链接——指定某个账号的专属链接，或任何登录用户可接受的一次性开放链接；链接带有效期（默认 72 小时），接受后自动以指定角色加入项目
- **可见范围**：物料资源、平台账号可单独设置「仅某些成员/角色可见」；可见范围的优先级高于权限点

## 进度追踪（待办）

- 待办事项支持：标题、**类别**（如美工/宣发/后勤）、**指派人**（多人）、**节点时间**、**到期时间**、**提醒时间**、备注
- 列表支持按类别、指派人、状态筛选，按创建/节点/到期时间排序
- **完成流程**：完成时可填写完成备注并上传附件（凭证文件，多文件）
- **邮件提醒**：配置 SMTP 后，系统通过定时接口扫描到达节点/到期时间的待办，自动邮件通知指派人；同一待办同一类提醒只发一次
- **模板复用**：可将当前项目的待办列表导出为 JSON 模板；在新项目中以开始或结束时间为锚点导入，每个待办的时间按相对偏移自动重算——适合系列活动复用筹备流程

## 财务模块

- **收支记录**：记录收入/支出，包含金额、备注、添加人、实际付款人、参与平摊人（不选则全员平摊），可上传截图等凭证附件
- **门票盈亏**：设置门票单价与售票数量后，门票收入实时计入项目盈亏
- **汇总与结算**：
  - 实时计算总收入、总支出与盈亏
  - 按人净额：谁垫付了多少、应分摊多少，一目了然
  - **建议转账**：自动生成人与人之间最简转账列表（含垫付报销与盈亏分配），金额精确到分且账目守恒；指定平摊人的专项支出仅由平摊人承担，不进入公款分配
- **按人导出 CSV**：导出某个成员相关的全部账目（UTF-8 带 BOM，Excel 可直接打开）

## 物料管理

- **资源类型**：自定义分类（如海报、宣传图、场地图）
- **多版本资源**：每个资源可反复上传新版本，展示默认最新版，可通过版本列表查看/下载历史版本
- **图片预览**：图片上传时自动生成 WebP 预览图（≤800px 宽，体积控制在 100KB 以内），列表快速加载预览，点击放大时加载原图
- **可见范围**：资源类型或单个资源可设置仅指定成员/角色可见；文件下载接口同样执行可见范围校验，撤销可见后立即不可下载
- 删除资源时级联清理所有版本与磁盘文件

## 平台账号管理

用于团队共用的各类平台账号（宣传账号、联系人等），三种记录模式：

| 模式 | 内容 | 用途 |
| --- | --- | --- |
| 完整账号 | 平台 + 账号 + 密码 | 团队共用登录 |
| 仅账号（OTP 辅助） | 平台 + 账号 + 添加人 | 需要二步验证时快速找到持有者索取验证码（展示添加人联系方式） |
| 仅联系人 | 平台 + 账号 + 备注 | 纯联系人记录 |

- **平台类型**：QQ、小红书、B 站、微博等，可按平台筛选
- **密码安全（默认）**：密码在浏览器内用用户自设的「保险库口令」加密（PBKDF2 + AES-GCM，`ANONv1` 格式）后才上传，**服务端只存密文、无法解密**；查看时在浏览器输入口令本地解密。口令遗忘无法找回
- **服务端加密（可选）**：也可选择由服务端使用环境密钥（`PLATFORM_CRYPTO_KEY`）AES-256-GCM 加密，查看时由服务端解密返回，便于团队共享而无需传递口令
- 每个账号可设置可见范围

## 界面与体验

- **移动端优先**：单列卡片布局，手机操作友好；宽屏自动分栏
- **日/夜主题**：右上角按钮一键切换，偏好本地记忆，首屏无闪烁
- 项目工作台以 Tab 组织：待办 / 财务 / 物料 / 账号 / 成员 / 角色 / 设置

## 安全设计摘要

- bcrypt 密码哈希、JWT 鉴权、生产环境强制 `JWT_SECRET`
- 所有受保护接口校验项目成员身份与权限点，可见范围优先
- 平台账号密码默认浏览器端加密，服务端零明文
- 文件下载全部鉴权（项目成员 + 可见范围），邀请链接一次性且带过期
- 定时提醒接口由独立密钥（`CRON_SECRET`）保护
